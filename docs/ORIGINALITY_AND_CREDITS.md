# Originality and credits

## What was written for this project

- All page copy, lesson text, quiz and challenge content, glossary entries, and UI strings.
- All imagery: there is none beyond vector art. The three medals (`src/assets/badges/*.svg`), the favicon, the key art and every chart are authored in this repository. The key art (`src/ui/KeyArt.tsx`) is generated by code from seeded random numbers and from the learner's saved state; the medals were generated by a script and committed as plain SVG. None of it is hand-drawn.
- All 3D geometry: the layered particle topology (`modules/ModuleA/topology.ts`) and the icosphere (`modules/ModuleC/icosphere.ts`) are generated by code in this repository.
- All shaders except the noise function noted below: `src/gpu/glsl/*`, `src/gpu/wgsl/*`, `src/gpu/tsl/*`.
- The Rust crate `crates/core` (SHA-256, HMAC, ChaCha20, Perlin noise, spatial hash, particle integrator). Test vectors for SHA-256, HMAC and ChaCha20 come from the public standards (FIPS 180-4, RFC 4231, RFC 8439) and were cross-checked against OpenSSL.
- The gamification engine, persistence, integrity layers, router, spring solver, master loop, quality governor and build plugins.

No stock photography, video, audio or icon packs are used. Two open-licensed typefaces (SIL Open Font License 1.1) are bundled and served from this site, Latin subset only: Big Shoulders Display (headlines, labels and numerals) and Barlow (text). They are installed as the `@fontsource` packages, listed below and on `/credits`; no request leaves the site for them. If a face must go, delete `src/styles/fonts.css` and the package, and the system stack named after it in `tokens.css` takes over.

## Visual references

The visual direction is the front end of a competitive game, inspired by the VALORANT interface, as described (with the evidence behind it, and its limits) in [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md). What was taken is general technique and mood: a dark full-width screen, art-first compositions, a light trapezoid tab for the current section, thin lines and small capitals, hard-edged panels with corner brackets, one hue grading each screen, filled buttons. No artwork, logo, character, name, typeface, screenshot, colour file or layout from any game or publisher is used, and nothing was traced. The key art, medals and every other illustration are authored from scratch in this repository, and several are built from the learner's own saved state. The 14 Riot images that were looked at during research were not copied into the repository.
